# Acceptance Matrix

Status values:

- Implemented: available in current code.
- Partial: foundation exists, but business behavior is missing.
- Planned: documented but not implemented.
- Out of MVP: intentionally deferred.

## MVP Summary

Release `0.1.0` includes Goals 0 through 7 plus the local provider-neutral mock workflows of Goals 8 and 9. Every
included row above is implemented and exercised by the repeatable release verifier. Goal 10, real healthcare
integrations, multiple signers per Report, qualified signatures, accredited FSE transport and accredited
preservation remain explicitly deferred.
