# SignFlow 0.1.0

First repeatable local MVP demonstration release.

## Included

- Authenticated administrator, signer and independent approver web workflows.
- REST/local MLLP HL7 v2 ingestion and SourceSystem-driven document pipeline.
- Explicit Report workflow, preview, review, approval, mock single/batch signature and append-only timeline.
- Provider-neutral local PAdES technical test engine using in-memory test certificates.
- Mock FSE 2.0 and conservation workflows with receipt storage, retry and reconciliation.
- Administration, monitoring, configurable UI texts, health checks and fictional demo data.
- Repeatable release gate, migration qualification, dependency/privacy scans and documented PostgreSQL/MinIO backup/restore.
- Spring Boot 3.5.14 with patched maintenance dependencies and Next.js 16.3.0; npm audit and Trivy report no
  HIGH/CRITICAL dependency findings at qualification time.

## Known limitations and risks

- Mock signature artifacts are intentionally non-legal and are not digitally signed PDFs.
- No real remote signature provider, national FSE endpoint or accredited conservation service is connected.
- CDA clinical generation and certified PDF/A-3 conversion remain deferred adapters.
- One Report currently has one assigned signer; multiple signers are deferred.
- Local Keycloak identities, credentials and test certificates are not production security material.

## Before real healthcare use

Complete security/privacy threat modelling and DPIA, production IAM and vault integration, qualified-signature and
provider sandbox certification, FSE accreditation and official validators, accredited preservation integration,
clinical CDA/PDF-A validation, infrastructure hardening/HA/DR, observability/SIEM, penetration and load testing,
retention/legal review, operational governance, clinical validation and formal acceptance by the responsible organization.
